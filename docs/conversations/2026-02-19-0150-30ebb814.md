# Plan: AwsResourceCache model for permissions editor

## Context

Resource fetching in the permissions editor is currently disabled (commented out) because querying AWS resources (S3 buckets, DynamoDB tables, SQS queues, etc.) per service requires STS AssumeRole + List* API calls. Doing this on every HTMX mutation is too expensive. We need a DB-backed cache so resources are fetched once and served from the database on subsequent renders.

The cache is per-environment (not per-PermissionRequest) because AWS resources belong to the infrastructure, not to a specific editing session. Two users editing different apps in the same environment see the same S3 buckets.

## Step 1: Add `AwsResourceCache` model

**File:** `devopshero_app/models.py`

Add model after `PermissionRequest`:

```python
class AwsResourceCache(models.Model):
    """Cached AWS resource listings per environment and service."""
    environment = models.ForeignKey(Environment, on_delete=models.CASCADE, related_name="resource_caches")
    service = models.CharField(max_length=100)
    resources = models.JSONField(default=list, help_text="List of {arn, label} dicts")
    fetched_at = models.DateTimeField()

    class Meta:
        unique_together = [("environment", "service")]
```

No UUIDField primary key — auto-increment is fine for a cache table.

Generate migration: `uv run manage.py makemigrations`

## Step 2: Add cache-aware resource fetching to permissions service

**File:** `devopshero_app/services/permissions.py`

Add a function `get_resources_for_services(environment, services)` that:

1. Queries `AwsResourceCache` for all requested services in this environment
2. Identifies which services are missing from cache
3. For missing services: calls `iam_utils.list_resources_for_services(environment, missing_services)`
4. Bulk-creates `AwsResourceCache` entries for the newly fetched services
5. Returns the combined dict `{"s3": [{arn, label}, ...], ...}`

Also add `refresh_resources_cache(environment, services)` that:
1. Deletes existing cache entries for these services in this environment
2. Calls `iam_utils.list_resources_for_services` for all of them
3. Bulk-creates fresh cache entries
4. Returns the resource dict
