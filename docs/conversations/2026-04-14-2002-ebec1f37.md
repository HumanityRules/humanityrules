## Where

**`devopshero_app/services/infra_customer/secrets_utils.py`**

- **`purge_deleted_secrets()`** — finds secrets that are already **scheduled for deletion** (AWS’s recovery window) and **removes them for good** with `ForceDeleteWithoutRecovery=True`.

```135:170:devopshero_app/services/infra_customer/secrets_utils.py
def purge_deleted_secrets(session: boto3.Session, dry_run: bool) -> int:
    """Permanently delete all secrets that are scheduled for deletion."""
    sm_client = session.client("secretsmanager")
    
    # Get secrets scheduled for deletion
    all_secrets = list_secrets(session=session, include_deleted=True)
    deleted_secrets = [s for s in all_secrets if s["deleted_date"] is not None]
    ...
    for secret in deleted_secrets:
        try:
            sm_client.delete_secret(
                SecretId=secret["arn"],
                ForceDeleteWithoutRecovery=True,
            )
```

## How

1. Run from the repo (with `uv`), targeting a **connected** customer account via **`--account`** (name or AWS account ID; default is a specific account ID in the argparse default).
2. The script loads `.env`, runs Django setup, resolves `AWSAccount`, and builds a boto3 session via **`iam_utils.get_assumed_role_session`** into **`us-east-1`**.
3. **`--purge-deleted`** calls `purge_deleted_secrets`. Use **`--dry-run`** to only print what would be purged.
4. **`--list --include-deleted`** shows secrets that are still in the pending-deletion state (with scheduled deletion dates).

**Important:** This path only **finishes** deletion for secrets that are **already** in Secrets Manager’s “pending deletion” state. It is not a separate “delete any secret immediately” API in this repo—that would be a normal `DeleteSecret` (with recovery window) elsewhere (console/CLI), then `--purge-deleted` if you want to skip the wait. There is no other project entry point in the grep results for bulk permanent delete of arbitrary active secrets.

**Behavior:**
