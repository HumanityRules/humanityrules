### `delete-by-prefix` subcommand

- **Usage:** `uv run manage.py doh_secrets delete-by-prefix --account "<name-or-id>" --subprefix <prefix> [--org ...] [--dry-run] [--force]`
- **`--subprefix`** — Required, non-empty (after trim). Uses Secrets Manager’s **name prefix** filter, so every **active** secret whose name **starts with** that string is targeted.
- **Default:** `DeleteSecret` with **`RecoveryWindowInDays=7`** (recoverable window).
- **`--force`:** `ForceDeleteWithoutRecovery=True` (same idea as `purge-deleted` for immediate removal).
- **`--dry-run`:** Only lists what would be deleted.

Implementation:

1. **`secrets_utils.delete_secrets_matching_prefix`** — Lists with `Filters=[{"Key": "name", "Values": [subprefix]}]` and `IncludePlannedDeletion=False`, then deletes each match.
2. **`doh_secrets.py`** — New subparser, validation for empty `--subprefix`, module docstring updated with examples.

Typical examples:

```bash
uv run manage.py doh_secrets delete-by-prefix --account "CH Sandbox" --subprefix devopshero/default/some-app --dry-run
uv run manage.py doh_secrets delete-by-prefix --account "CH Sandbox" --subprefix devopshero/default/some-app
uv run manage.py doh_secrets delete-by-prefix --account "CH Sandbox" --subprefix devopshero/default/some-app --force
```
