Does the command doh_app_logs include a flag to tail the log?

---

## Assistant

No, `doh_app_logs` does not include a tail/follow flag. It fetches a batch of log events and exits. The available flags are:

- **`--limit`** — Number of events to fetch (default 100, reads from the end)
- **`--head`** — Read from the beginning instead of the end
- **`--all`** — Paginate through all events
- **`--stopped`** — Look at stopped/crashed tasks

There's no `--tail` or `--follow` flag that would continuously stream new log events as they arrive (like `tail -f`). Would you like me to add one?

## Assistant

Done. The command now supports `--follow` to continuously poll for new log events, and `--follow-interval` to control the polling rate (defaults to 2 seconds). Usage:

```
uv run manage.py doh_app_logs --account "CH Sandbox" --app my-app-slug --follow
uv run manage.py doh_app_logs --account "CH Sandbox" --app my-app-slug --follow --follow-interval 5
```

It prints the initial batch of logs, then enters a polling loop with a `--- following (Ctrl+C to stop) ---` banner. Ctrl+C exits cleanly.
