## Assistant

I'd go with **Option 2 (`doh-template://`)**. It keeps `repo_service.clone_repository()` as the single place that resolves sources, so the deploy executor and `AppConfigBuilder` don't have to learn the "is this a template?" branch — they just hand a URL off like they do for GitHub. Stored URLs also stay portable (no baked-in absolute path from the machine that created the app, no `$WORKTREE` tokens that look odd in logs/DB dumps), and the worker naturally uses its own `settings.TEMPLATE_REPOS_DIR`, which is what makes worktrees work.
