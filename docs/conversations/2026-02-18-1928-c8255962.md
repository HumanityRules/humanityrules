When I refresh the page I see a breakpoint in line 127 in security.py being hit multiple times. Why?

---

## Assistant

That's the app shell pattern. On a full page refresh, the view is called **twice**:

1. **First hit** — the browser's initial GET. `request.htmx` is `False`, so the view returns `app_shell.html` with `content_url` set to the current path.
2. **Second hit** — the app shell loads `content_url` via HTMX into `#main-content`. Now `request.htmx` is `True`, so it returns the partial template.

This is by design (see `views/CLAUDE.md` — "Direct URL access works: Views handle both htmx requests (return partial) and full page loads (return app_shell with content_url)"). It's the cost of the SPA-like navigation model: full refreshes pay for two requests so that HTMX navigations only pay for one.
