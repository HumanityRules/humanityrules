I’d treat the current top-right action on `devopshero_app/templates/devopshero_app/apps/app_detail.html` as the secondary entrypoint. That button should become state-aware:
- `Resume Setup` when the latest blueprint is `draft`
- likely `Resume Setup` or `Fix Deployment` when the latest blueprint is `failed` and the first deploy has not succeeded yet
