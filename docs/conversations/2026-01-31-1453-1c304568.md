## Assistant

`get_app_type_display` is a Django auto-generated method. For any model field with `choices` defined, Django automatically creates a `get_<field_name>_display()` method that returns the human-readable label.

From the App model:

```552:555:devopshero_app/models.py
app_type = models.CharField(
    max_length=20,
    choices=AppType.choices,
)
```

Where `AppType` is defined as:

```519:522:devopshero_app/models.py
class AppType(models.TextChoices):
    WEB = "web", "Web Service"
    WORKER = "worker", "Background Worker"
    SCHEDULED = "scheduled", "Scheduled Job"
```

So `app.get_app_type_display` returns "Web Service" instead of "web", "Background Worker" instead of "worker", etc.
