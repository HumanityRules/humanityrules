But you could unify them into a single function that takes strings directly — the `Exception`-based one is just doing `str(error)` and `type(error).__name__` anyway, which the caller could do before passing in. Something like:

```python
async def _persist_error(conversation: Conversation, error_type: str, error_description: str) -> None:
    """Persist an error message to the database."""
    await Message.objects.acreate(
        conversation=conversation,
        role=Message.Role.SYSTEM,
        content_type=Message.ContentType.ERROR,
        content=error_description,
        metadata={"error_type": error_type},
    )
```

Then the two call sites become:

- **API error** (line 394): `_persist_error(conversation=..., error_type=message.error, error_description=error_description)`
