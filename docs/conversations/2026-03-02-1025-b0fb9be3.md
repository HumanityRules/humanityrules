# Replace HTML5 datalist with Alpine.js combobox dropdown

## Context

All key-value tag/attribute inputs (people attributes, group attributes, workspace/app/environment tags, policy editor conditions) use HTML5 `<datalist>` for autocomplete suggestions. This causes inconsistent rendering across browsers, zero styling control, and browser autocomplete cache pollution that masquerades as app suggestions (documented in journal 2026-02-28).

The fix: replace every `<datalist>` + `<input list="...">` with a reusable Alpine.js combobox component. Alpine is already loaded globally in `base.html` and used extensively in `_permission_service_group.html` (dropdown pattern we'll follow as reference).

## Approach: Django template include with nested Alpine scope

Create a `_combobox_input.html` include that wraps a regular `<input>` in an Alpine.js `x-data="{ open: false }"` scope with a styled dropdown panel. The actual model variable lives in the **parent** Alpine scope (nested scopes inherit), so the include works in both contexts:

- **Simple tag forms:** Parent scope defines `key`/`value` local variables
- **Policy editor:** Parent scope already has `cond.key`/`cond.value` from `x-for`

Suggestion values stored in `data-value` attributes (safe HTML escaping) and read via `$el.dataset.value` (avoids JS string quoting issues — same pattern as `_permission_service_group.html:94`).

## Files to create

**`devopshero_app/templates/devopshero_app/_combobox_input.html`** — The reusable combobox include. Receives Django template variables:
- `suggestions` — list of suggestion strings
- `name` — input name attribute (for form submission)
- `model` — Alpine model expression (e.g., `"key"`, `"cond.key"`)
- `placeholder` — input placeholder text
- `width` — Tailwind width class (e.g., `"w-24"`)

Structure:
```html
<div x-data="{ open: false }" @click.outside="open = false" class="relative">
    <input type="text" name="{{ name }}" x-model="{{ model }}" placeholder="{{ placeholder }}"
           autocomplete="off" required
           @focus="open = true"
           @keydown.escape="open = false; $el.blur()"
           class="{{ width }} px-2 py-0.5 text-xs border ...">
    <div x-show="open" x-cloak x-transition.opacity.duration.50ms
         class="absolute z-50 mt-1 ...">
        {% for s in suggestions %}
        <button type="button" data-value="{{ s }}"
                x-show="!{{ model }} || $el.dataset.value.toLowerCase().includes({{ model }}.toLowerCase())"
                @click="{{ model }} = $el.dataset.value; open = false"
                class="...">{{ s }}</button>
        {% endfor %}
    </div>
</div>
```
