1. When you connect GitHub, the callback calls `github_client.get_installation_details(installation_id)` 
2. That function calls `generate_jwt()` which requires `GITHUB_APP_PRIVATE_KEY` to sign the JWT for GitHub API authentication
3. If the key is missing/invalid, the API call fails, and the exception handler in `github_callback` (line 86-97 of `github.py`) sets the integration status to ERROR


**To fix it**, you'd need to:
1. Download the private key from your GitHub App settings (Settings > Developer settings > GitHub Apps > devops-hero-app > Generate a private key)

3. Click "Reconnect" in the UI to re-trigger the OAuth flow
