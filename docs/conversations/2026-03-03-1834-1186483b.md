**Modify: `auth_callback(request)`** — handle both providers:

- If `"workos"` (or absent): existing WorkOS flow unchanged

## User

what is the "OIDC subject identifier"?

---

## Assistant

The OIDC subject identifier (`sub`) is a unique, stable string that the identity provider (e.g. Okta) assigns to each user. It's the OIDC equivalent of `workos_user_id` — the external ID we use to match a returning user to their local `User` record.

It comes back in the userinfo response after token exchange, and it's guaranteed to be unique and not change for a given user within that provider.
