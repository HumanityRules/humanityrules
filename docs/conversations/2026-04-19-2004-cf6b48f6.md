### `doh_secrets shared-set-from-env`

**Usage:**
```bash
uv run manage.py doh_secrets shared-set-from-env \
  [--org ORG] \
  --account ACCOUNT \
  --env ENV_SLUG \
  --file PATH_TO_ENV \
  KEY [KEY ...]
```

**Behavior:**
- Resolves `--file` with `pathlib.Path` (relative paths use the process cwd).
- Loads the file via `dotenv_values` (same idea as [`infra_devopshero/sync_secrets.py`](infra_devopshero/sync_secrets.py)).
- Requires every listed `KEY` to be present with a non-`None` value (empty string is allowed, matching `KEY=` on the CLI).
- Builds `KEY=VALUE` strings and calls existing `_run_shared_set`, so merging into `devopshero/{env}/shared-secrets` matches `shared-set`.

**Docs:** Module docstring and subcommand list in [`devopshero_app/management/commands/doh_secrets.py`](devopshero_app/management/commands/doh_secrets.py) are updated; `shared-set-from-env --help` runs cleanly.
