**What's missing:**

1. **A `doh_query` management command** for ad-hoc model inspection. Something like:
   ```bash
   ./prod_manage.sh doh_query Repository full_name default_branch --filter "full_name__icontains=ai-detector"
   ```
   This avoids passing Python code through shells entirely.

2. **The skill file** should document the quoting limitation and recommend simple one-liners without nested quotes (what finally worked was `[print(r.full_name, r.default_branch) for r in Repository.objects.all()]` - no string literals with quotes).

**Recommendation:** Add a `doh_query` command. It's the cleanest fix because:
- No quoting issues - model/field names are simple strings
- Covers 90% of debugging needs (inspecting model data)
- Reusable pattern for any model
