The Platform

Trust, built into
every layer

Models change. Agent frameworks change. Your governance layer shouldn't be disposable. Humanity Rules is the durable control plane for agent access, tools, memory, approvals, and audit — with security defaults that just make sense.

Runs in your cloud

Every agent is deployed into your own AWS VPC — sandboxed, isolated, and always-on. Your data stays inside your perimeter.

No model lock-in

Bedrock, hosted APIs, open-source, OpenRouter — switch providers without re-platforming. Orchestrate models by cost and performance.

Curated, audited skills

An allowlist of reviewed, versioned skills and MCP servers. Every entry passes security review — automated and human — before your team can use it.

ABAC & approvals

Fine-grained, attribute-based access control decides what each agent can see and do. Sensitive actions gate through human approval workflows.

SSO & audit trails

Okta / WorkOS sign-in out of the box. Action-level audit — prompts, tools, approvals, outcomes — built for compliance and security review.

Secured integrations

Brokered egress, scoped credentials, and approval gates for Slack, GitHub, Notion and any MCP server — with SIEM-exportable logs. Agents never touch raw secrets.
