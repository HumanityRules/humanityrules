The Platform

Trust, built into
every layer

Runs in your cloud

Agents run in your AWS account, not ours. We never see your conversations or data.

Sovereign AI

Run on Bedrock and prompts never leave your network. Use OpenRouter, hosted API Keys, or open-source models. Switching providers is one admin setting.

Secured integrations

Credentials for every connector, for example GitHub or Notion, live in a broker; agents call through it and never see the token.

Approvals

ABAC policies decide what each agent can see and do, and which actions need a human okay first.

SSO & audit trails

Sign in with Okta or WorkOS. Every prompt and tool call is in the log, tied to the user who asked for it.

The allowlist

Your agents only get vetted skills and MCP servers. Nothing installs from a public registry at runtime.
