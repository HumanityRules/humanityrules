{% comment %} Reusable combobox input with Alpine.js dropdown suggestions. Template variables: suggestions — list of strings (key mode) or list of (key, value) tuples (value mode) name — input name attribute (for form submission; omit for Alpine-only) model — Alpine model expression (e.g. "key", "cond.key") placeholder — input placeholder text width — Tailwind width class (e.g. "w-24") input_class — optional full class override (replaces width + defaults) required — if truthy, adds required attribute for_key_model — Alpine expression for the associated key (e.g. "key", "cond.key"). When set, suggestions must be (key, value) tuples and the dropdown only opens / shows items when the key has a value. value_model — Alpine expression for a separate "selected value" (e.g. "selectedId"). When set, suggestions must be (value, label) tuples. The text input displays/filters by label (bound to model), while on selection value_model is set to the tuple's value. Typing clears value_model. value_name — input name for the hidden value field (for form submission with value_model). clear_model — Alpine expression to reset to '' on input/selection (e.g. "item.value"). Useful for clearing a paired value field when the key changes. type_filter_model — Alpine expression holding a resource-type string (e.g. "resourceType"). When set, each suggestion carries a trailing comma-joined "resource types" element and is only shown when that model's value is empty or listed among the suggestion's types. Suggestion shapes gain the extra element: plain mode -> (value, types_csv); for_key_model mode -> (key, value, types_csv). The actual model variable lives in the PARENT Alpine scope (nested scopes inherit). {% endcomment %}
