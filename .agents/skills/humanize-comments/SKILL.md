---
name: humanize-comments
description: Rewrite a file's comments into digestible plain language when they have grown dense.
disable-model-invocation: true
argument-hint: "[file | which comments]"
---

Target: $ARGUMENTS (default: the file currently in focus)

The comments in the target file have expanded and are not human friendly in
the sense of helping build a mental model of what's going on. Rewrite them to
make them more digestible in human plain language.
