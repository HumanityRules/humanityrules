Please don't apply yet if...

Compatibility exclusions

  • You need least-privilege AWS access today. Route: wait; this changes when the deployment role narrows.
  • You need production SLAs today. Route: wait, or run a hosted plan in the meantime.

Selective exclusions

  • You cannot name an infrastructure owner. Route: Trial or Operator.
  • You cannot name one concrete workflow you will exercise and discuss. Route: Trial.

Before you apply

  1. Deploying into your AWS account currently requires a role with AdministratorAccess: broad administrator access, not a least-privilege role.
  2. OAuth refresh tokens and pasted provider keys, where used, are stored in HumR's database: vendor custody, not yours.
  3. The agent's runtime state, conversation history, working files, logs, and infrastructure live in your AWS account.
  4. The control plane, credential brokerage, deployment machinery, and parts of the runtime depend on HumR.

No external organization runs a HumR agent in its own AWS account yet. The machinery is exercised daily against my own account; this program exists to change that, one partner at a time.
